# Продукт

Yaskapp позволяет задать вопрос с вариантами ответа, собрать голоса и обсудить
результат. Ниже — поведение текущего кода; состояние конкретного сервера проверяется
[перед выпуском](staging-smoke-test.md).

## Основные сценарии

| Возможность | Правила |
| --- | --- |
| Аккаунт | Регистрация, вход, профиль, страна, аватар и подписки. Для действий нужна авторизация; публичный контент можно читать гостем. |
| Опрос | Вопрос до 280 символов, от 2 до 6 вариантов, необязательное изображение и срок окончания. |
| Голосование | Один голос пользователя на опрос. Переключить вариант напрямую нельзя. Если автор разрешил отмену и опрос ещё открыт, голос можно отозвать, затем проголосовать снова. |
| Лента | Свежие и популярные опросы, подписки, опросы конкретного профиля. Догрузка ленты управляется флагом сборки. |
| Поиск | Опросы по вопросу, пользователи по username и имени; запрос от 2 до 100 символов. |
| Обсуждение | Корневые комментарии и один уровень ответов. Комментарий до 1 000 символов; ответить на ответ нельзя. Удаление корня скрывает его ответы. |
| Реакции | Лайки опросов и комментариев с возможностью отмены. Счётчики обновляются вместе с изменением данных. |
| Уведомления | Голос, комментарий, ответ на комментарий, лайк и подписка. Настройки in-app и push раздельные для каждого типа. |
| Модерация | Жалобы, дела, санкции, апелляции, аудит и управление политиками; доступ определяется ролью и полномочиями. |
| Удаление аккаунта | Подтверждение паролем, немедленное закрытие доступа и фоновая очистка. Есть [ограниченный архив для модерации](account-deletion-operations.md). |

Открытие раздела уведомлений само по себе не отмечает всё прочитанным.
Ответ на комментарий уведомляет автора корня; собственные действия не создают
уведомление самому себе. После reconnect или возвращения в приложение состояние
сверяется с сервером.

## Что ещё не выпущено

| Работа | Подтверждённый статус |
| --- | --- |
| Личная блокировка | Утверждены правила, подготовлены тестовые данные. Серверная защита и интерфейсы ещё не реализованы. [Требования](prd-user-blocking.md). |
| Пагинация ленты | Код и флаги есть, по умолчанию выключены. На 28 октября 2026 staging, rollout и rollback не проверены; выпуск не подтверждён. |
| Анимации реакций и появления | Флаги по умолчанию выключены. На 10 октября 2026 проверки производительности и жизненного цикла не закрыты; разрешения на rollout нет. Skeleton остаётся статичным. |
| Привязка домена | Существующие локальные черновики описывают переход на `yaskapp.org`. Код мобильного клиента пока содержит HTTP-адрес staging; для нужного окружения задаются явные адреса сборки. |

Личная блокировка — отдельная будущая функция. Административный бан уже существует
и ограничивает аккаунт на всей площадке.
